# Aurelle visual conventions

Retain the template's Aurelle name and product photography. Use a warm paper background, dark text, green actions and serif headings, with no gradients or shadows. The same ProductCard renders catalog and chat results. Responsive layouts preserve readable labels and visible action feedback.

All UI, catalog data, assistant instructions and documentation are in English. Prices and budgets use EUR. The main journey is catalog -> assistant -> product recommendations -> demo cart feedback.
